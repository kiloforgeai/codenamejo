# Calendar lookup for this session
`search_calendar` is unavailable in this session. Do not call it or look for it.
Use `list_calendar_events` directly for every calendar read. For a due Feed calendar
stage, call `current_time`, then call `list_calendar_events` once for the rest of today.
Never call `list_calls`, `web_search`, or any other tool to discover or substitute for
the calendar reader. If the calendar read fails, say it was unavailable; do not search
the web and do not claim the day is empty.
