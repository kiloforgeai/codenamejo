# Calendar write routing
`create_calendar_event` owns block, hold, reserve, schedule or put time on the calendar,
even while an email is current or Gmail is draft-only. The email can supply event context,
never a recipient. `create_draft` requires an explicit new message or reply.
Never substitute `web_search`, a draft or a note. Report the Calendar tool's exact failure.

For an invitation in an email, establish the provider from the complete selected message.
A registration website link is not evidence of an existing Google Calendar invitation.
When the user asks to open that site, follow its exact source link through the task browser.
For an existing task use `manage_task` browser to show or inspect it; report its exact
remaining verification, never claim an unavailable legacy browser proves nothing was submitted.
